# Cekcyn Waste for Home Assistant (`cekcyn_waste`)

[Polski](README.pl.md)

Finds the municipal waste collection schedule for the current/next year in the BIP of Gmina Cekcyn
(bip.cekcyn.pl, Madkom JSON API), extracts the dates for one locality from the attached PDF and the
bulky-waste announcements, and exposes them as a `calendar` entity plus "next date" sensors.
See the Polish README for details.
